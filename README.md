# Vintage Cam

브라우저 안에서 사진을 보정하는 가벼운 필터 앱입니다. `index.html`을 열면 바로 사용할 수 있고, 사진은 서버로 전송되지 않습니다.

## 필터 구성

원본을 제외하면 총 32종입니다. 90년대·빈티지·레트로 컬렉션 16종과 기존 16종을 함께 제공합니다. 특정 제조사의 필름이나 센서를 정확히 재현한 제품이 아닌 자체 프리셋입니다. 이름의 연도는 분위기를 표현하며 사진에 날짜가 찍히지는 않습니다.

클라렌던, 깅엄, 라크, 문도 그대로 선택할 수 있습니다. ‘문’은 흑백과 기존 필터 카테고리 양쪽에 표시됩니다.

색감 기획은 [VSCO 프리셋 가이드](https://support.vsco.co/en/articles/12698471-preset-guide)와 [Adobe의 2025 창작 트렌드 회고](https://blog.adobe.com/en/publish/2026/01/08/halftone-nostalgia-more-2025-top-firefly-prompt-trends)를 참고했습니다. 인기 순위를 재현한 목록은 아닙니다.

빛 번짐 표현은 [Dehancer의 Bloom 설명](https://www.dehancer.com/learn/articles/bloom-how-it-works)과 [Halation 설명](https://www.dehancer.com/learn/article/halation)을 참고했습니다. 효과 구현은 이 프로젝트의 자체 근사 알고리즘입니다.

## 사용 방식

1. 사진을 선택합니다. 긴 변이 1440px를 넘으면 비율을 유지해 축소합니다.
2. 필터 썸네일이나 90년대·빈티지·레트로 등의 카테고리에서 원하는 색감을 고릅니다. 카테고리와 필터 목록은 가로로 넘길 수 있습니다.
3. 기본 강도는 80%이며, 0~100%로 조절할 수 있습니다. 썸네일은 기본 강도 기준입니다.
4. `원본 비교`를 눌러 보정 전후를 확인합니다. 비교 중 저장해도 선택한 필터가 적용됩니다.
5. `저장하기`로 JPEG를 다운로드합니다. 투명한 부분은 흰색으로 저장됩니다.

모든 효과는 보관한 원본에서 다시 계산합니다. 같은 사진에서 필터를 재선택해도 입자 패턴이 유지됩니다. 새 사진을 선택하면 원본·강도·카테고리가 초기화됩니다.

강도를 조절할 때는 현재 선택한 필터의 계산 결과를 재사용합니다. 전체 필터의 고해상도 이미지를 메모리에 쌓아두지 않습니다.

## 파일

- `index.html`: 편집 화면과 컨트롤
- `style.css`: 모바일 화면, 필터 카드와 슬라이더
- `script.js`: 이미지 로딩, UI 상태, 미리보기, 저장
- `filters.js`: 필터 목록, 톤 커브, 색 보정, 입자, 빛 번짐, 렌즈·인화 질감

Canvas의 CSS `filter` 지원 여부에 의존하지 않는 픽셀 연산을 사용합니다. 기존 필터는 기존 색 보정 수식을 옮겼으며, 브라우저 기본 필터의 반올림과 비네팅 모양에는 차이가 있을 수 있습니다.

## 검증

Node.js가 있으면 `node --test tests/filter-engine.test.cjs tests/ui-cache.test.cjs`로 필터 연산과 강도 조절 캐시를 검사할 수 있습니다. JavaScript 문법은 `node --check filters.js`와 `node --check script.js`로 검사합니다.

브라우저 통합 검사는 프로젝트 폴더에서 다음 서버를 실행한 뒤 `http://127.0.0.1:8765/tests/browser-tests.html`을 엽니다.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

업로드, 33개 선택지, 강도, 원본 비교, JPEG 생성, 오류 복구, 사진 교체, 투명도, 모바일 배치를 검사하고 PASS/FAIL을 표시합니다. 검사 후에는 골드 200 미리보기가 남습니다. 이 테스트 페이지는 같은 출처의 iframe을 사용하므로 파일을 직접 여는 대신 로컬 서버가 필요합니다.

실사진 결과 비교는 Pillow와 Node.js가 있는 환경에서 `python tests/photo-previews.py`로 실행합니다. `test_img`의 원본을 읽기만 하고, 실제 필터 엔진의 결과와 비교판을 Git에서 제외한 `.preview-temp/analog-quality/`에 생성합니다. 이 검사는 브라우저 UI 검사와 별개입니다.
