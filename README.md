# Vintage Studio

필름·빈티지·90년대 인화사진·초기 디지털카메라의 색감을 편집하는 로컬 사진 앱입니다. 큰 미리보기, 44가지 필터, 수동 보정, 전후 비교와 나만의 레시피를 하나의 작업 화면에 담았습니다. 별도 설치나 계정 없이 사용하며 사진은 서버로 전송하지 않습니다.

## 실행

`index.html`을 브라우저에서 열면 번들 샘플 사진으로 시작합니다. 사진 열기, 파일 끌어놓기 또는 이미지 붙여넣기로 내 사진을 편집하세요. JPG·PNG·WebP 등 브라우저가 해석할 수 있는 이미지가 지원됩니다.

Worker를 이용한 백그라운드 처리와 브라우저 통합 검사는 로컬 HTTP 서버에서 실행합니다.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

앱 주소는 `http://127.0.0.1:8765/`입니다. 파일을 직접 열거나 Worker 기능을 사용할 수 없는 환경에서는 메인 스레드에서 처리합니다. 큰 사진과 복잡한 필터는 이 환경에서 잠시 화면 응답을 늦출 수 있습니다.

## 편집 기능

- **44가지 룩 + 원본:** 사진 썸네일, 분위기 검색, 컬렉션과 즐겨찾기로 선택합니다. `새로운 룩`에서 추가된 12종을 모아볼 수 있습니다. 사진의 밝기·채도·색 균형을 바탕으로 새 필터와 기존 필터를 함께 추천합니다.
- **필터 강도:** 기본 80%, 0~100% 조절. 썸네일은 기본 강도의 필터 색감을 보여줍니다.
- **세부 조정:** 노출(−1~+1 EV), 대비, 하이라이트, 그림자, 색온도, 채도, 페이드, 추가 입자와 비네팅.
- **필름 디테일:** 피부색 보호, 필터 질감, 빛 번짐과 붉은 잔광을 개별 조절합니다. 질감을 줄여도 필터의 색과 대비는 유지됩니다.
- **구도:** 90° 회전 및 원본·1:1·4:5·3:2·9:16 비율. 자르기는 사진 중앙을 기준으로 합니다.
- **전후 비교:** 분할 슬라이더로 비교하거나 Space를 누르고 있는 동안 원본을 봅니다. 비교 화면에도 동일한 회전과 자르기를 적용합니다.
- **편집 기록:** 최대 40개 상태를 되돌리거나 다시 실행합니다. Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl/Cmd+Y를 지원합니다.
- **레시피:** 필터·강도·보정·회전·비율을 함께 최대 24개 저장하고 다른 사진에 적용합니다.
- **내보내기:** JPEG 또는 투명도를 유지하는 PNG. 긴 변 기준 1440·2560·4096px 중 선택하며 작은 사진을 확대하지 않습니다. JPEG 품질은 70~100%이며 투명 영역은 흰색으로 저장합니다.

사진을 새로 열면 보정과 편집 기록을 초기화합니다. 즐겨찾기와 레시피는 브라우저의 로컬 저장소에 남습니다. 저장소를 지우면 함께 삭제되며, 다른 기기·브라우저·사이트 주소와 동기화하지 않습니다. 사진 자체와 현재 편집 세션은 저장하지 않으므로 새로고침 전에 결과를 내보내세요.

## 사진 품질과 필름 디테일

엔진 개선판은 밝은 영역의 계조, 과포화 색, 피부색과 광원 주변 표현을 중심으로 처리합니다. 44개 필터의 이름과 저장된 레시피를 계속 사용할 수 있으며, 새로운 처리 방식에 따라 이전 버전과 결과가 달라질 수 있습니다. 기존 레시피에 없는 새 조절값은 아래 기본값으로 채웁니다.

| 조절 | 기본값 · 범위 | 용도 |
| --- | --- | --- |
| 하이라이트 | 0 · −100~100 | 밝은 영역의 명도를 부드럽게 조절 |
| 그림자 | 0 · −100~100 | 어두운 영역의 명도 조절 |
| 피부색 보호 | 60% · 0~100% | 따뜻한 색 범위의 과도한 색 변형 완화 |
| 필터 질감 | 100% · 0~150% | 프리셋에 포함된 입자·색 노이즈·먼지의 양 |
| 빛 번짐 | 100% · 0~150% | 밝은 광원 주변에 퍼지는 부드러운 빛 |
| 붉은 잔광 | 100% · 0~150% | 밝고 어두운 영역의 경계에 생기는 따뜻한 번짐 |

100%는 해당 필터가 의도한 기본 질감·번짐이고 0%는 그 효과를 끕니다. 선택한 필터에 없는 효과는 조절할 수 없도록 표시합니다. `추가 입자`는 필터 질감과 별도로 입자를 더합니다. 완전히 깨끗한 결과를 원하면 필터 질감과 추가 입자를 모두 0으로 맞추세요.

피부색 보호는 얼굴을 찾거나 피부를 매끈하게 만드는 기능이 아닙니다. 입력 사진의 따뜻한 색 범위에서 색차를 보호하며 비슷한 색의 벽·나무·옷에도 영향을 줄 수 있습니다. 흑백·세피아 필터에는 적용하지 않습니다.

노출을 높일 때 선형화한 색 값을 곧바로 자르지 않고 밝은 영역에서 부드럽게 압축합니다. 예를 들어 회색 188·200·216·232·248은 이전 +1EV 처리에서 모두 255가 되었지만, 개선판에서는 서로 다른 밝기를 남깁니다. 원본에서 이미 사라진 하이라이트를 복구하는 기능은 아닙니다.

필터 곡선을 소수 단위로 보간하고 색역 경계에서는 명도와 색차를 분리해 압축합니다. 필터 강도도 소수 정밀도로 혼합한 뒤 최종 픽셀에 기록합니다. 광원 에너지는 선형화한 값으로 계산하고, 붉은 잔광은 광원 주변의 대비 경계에 제한합니다. 사진 좌표에 고정된 여러 크기의 입자를 사용해 출력 크기를 바꿀 때 전체적인 입자 크기와 분포가 유지되도록 합니다.

인물에서는 피부색 보호 60~85%, 필터 질감 30~70%부터 조절하면 과한 색 변형과 입자를 줄일 수 있습니다. 밤거리에서는 빛 번짐과 붉은 잔광을 따로 조절하세요. 원본과 분할 비교하면서 과한 효과를 줄이고, 마음에 드는 조합을 레시피로 저장할 수 있습니다.

## 구조와 처리 범위

| 파일 | 역할 |
| --- | --- |
| `index.html` | 편집 화면, 접근성 레이블, 저장·레시피 대화상자 |
| `style.css` | 데스크톱과 모바일 레이아웃, 키보드 포커스와 모션 설정 |
| `script.js` | 사진 로딩, UI 상태, 기록·레시피, 작업 큐와 내보내기 |
| `filters.js` | 44개 필터와 픽셀·공간 효과 엔진 |
| `editor-core.js` | 회전·자르기, 수동 보정, 필터 추천, 공통 렌더링 |
| `render-worker.js` | OffscreenCanvas 기반 미리보기·저장 백그라운드 처리 |
| `assets/` | 공개 샘플 사진, 직접 파일 실행용 데이터와 출처 |
| `tests/` | 필터·보정·작업 큐 검사와 브라우저 통합 검사 |

원본은 긴 변 최대 4096px로 불러오고 미리보기는 최대 1440px로 처리합니다. 내보내기는 보관한 원본에서 선택한 크기로 다시 렌더링합니다. 확대 복원, RAW 현상, HDR·광색역 보존 또는 전문 인쇄용 색상 관리는 제공하지 않습니다. 출력 해상도별 샘플링과 JPEG 압축 때문에 미세한 픽셀은 달라질 수 있습니다.

Worker는 한 번에 한 작업을 처리하며, 연속 슬라이더 입력은 최신 미리보기 요청으로 모읍니다. 사진을 바꾼 뒤 도착한 이전 결과는 표시하지 않습니다. 구도가 바뀌지 않으면 Worker가 비교용 원본을 재사용하고 전달된 비트맵을 사용 후 해제합니다. 별도 라이브러리, 빌드 과정, 외부 폰트나 런타임 API에 의존하지 않습니다.

## 검증

2026년 11월 10일 품질 개선판에서 자동 검사 57개를 통과했습니다. 밝은 계조·과포화 색·피부색 보호·해상도별 입자 일관성·투명도와 저장 작업을 포함합니다. 공개 샘플과 로컬 사진 총 4장으로 개선 전후 필터·노출 결과 68개도 비교했습니다. 공개 사진의 비교판은 `.preview-temp/premium-quality/photo-1/`에 있으며 개인 사진 결과는 Git에서 제외한 로컬 QA 폴더에만 보관합니다.

4096×2731 이미지의 네온 다이어리·포켓 디카 렌더링도 원본과 알파를 보존하며 완료했습니다. 이 환경에서 순수 픽셀 엔진은 각각 약 3.33초·3.91초였고, 사진 디코딩·브라우저 화면·JPEG/PNG 인코딩·전체 내보내기 시간은 포함하지 않습니다. 모바일 실기기의 속도와 메모리 사용은 별도 확인이 필요합니다.

Node.js에서 다음 명령으로 수치 처리와 컨트롤러·작업 큐를 검사합니다.

```sh
node --test tests/filter-engine.test.cjs tests/editor-core.test.cjs tests/ui-cache.test.cjs tests/studio-controller.test.cjs
```

`ui-cache.test.cjs`는 기존 파일명을 유지하며 현재 Worker 캐시·작업 조정 동작을 검사합니다. 컨트롤러 검사는 실제 `script.js`를 DOM/Canvas 스텁에서 실행하므로 실제 브라우저의 배치·이미지 디코딩·다운로드 확인을 대신하지 않습니다.

로컬 서버를 실행한 다음 `http://127.0.0.1:8765/tests/browser-tests.html`을 열면 브라우저 통합 검사 결과를 확인할 수 있습니다. 필터 선택·검색·즐겨찾기·보정·편집 기록·레시피·PNG/JPEG 인코딩·오류 복구·모바일 배치를 검사합니다. 테스트 전 저장된 즐겨찾기와 레시피는 종료 시 복원합니다. 실제 다운로드와 화면 품질은 앱에서도 직접 확인하세요.

실사진 비교용 `tests/photo-previews.py`는 Pillow와 Node.js가 필요합니다. `test_img` 원본은 읽기만 하고 결과를 Git에서 제외한 `.preview-temp/analog-quality/`에 생성합니다. 개인 테스트 사진은 앱에 포함하지 않습니다.

## 출처와 참고

2026년 11월 추가 컬렉션은 [VSCO Capture의 필름 입자·Bloom·Halation 가이드](https://www.vsco.co/learn/getting-started-vsco-capture), [Aftershoot의 2026 사진 트렌드](https://aftershoot.com/blog/wedding-photography-trends/)에 소개된 플래시·필름 표현을 참고했습니다. 디카, 부드러운 인물색, 여행 크롬과 밤거리 룩으로 나눈 구성은 이 앱을 위한 자체 기획이며 인기 순위를 의미하지 않습니다.

명도와 색차를 나눠 다루는 접근은 [ACES 색차 압축 설명](https://docs.acescentral.com/system-components/output-transforms/technical-details/chroma-compression/), 광원 경계의 따뜻한 번짐은 [Dehancer Halation 설명](https://www.dehancer.com/learn/article/halation)을 참고했습니다. 이 앱은 브라우저에서 처리하는 sRGB 사진용 자체 근사 알고리즘을 사용합니다.
